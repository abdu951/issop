# Issue Reporting & Management System

A full-stack system that allows citizens to report public issues, administrators to assign them, and agents to resolve them — with real-time notifications.


## Features

* Authentication (JWT-based)
* Role-based authorization (Admin / Agent / Citizen)
* Issue reporting with image upload (Cloudinary)
* Location-based issue submission
* Admin issue assignment
* Agent workflow (accept / reject / resolve)
* Real-time notifications (Socket.IO)
* Structured, scalable backend architecture


### Tech Stack

* **Backend**: Node.js, Express.js
* **Frontend**: Next.js + Tailwind CSS
* **Database**: Prisma ORM + PostgreSQL
* **Authentication**: JWT (access tokens)
* **File Upload**: Cloudinary
* **Real-time**: Socket.IO
